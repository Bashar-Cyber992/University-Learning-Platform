🎯 أهداف المقرر ومخرجات التعلم

  • فهم الأسس النظرية لتحليل وتصميم نظم المعلومات ومكوناتها الخمسة وعناصر البيئة المحيطة.
  • إتقان مراحل دورة حياة تطوير النظم (SDLC) من التخطيط والتحليل حتى التصميم والتنفيذ والصيانة.
  • التعرف على المهارات والصفات الأساسية لمحلل النظم والأدوار التخصصية المختلفة في فرق العمل.
  • استخدام أدوات النمذجة المنطقية والمخططات البيانية (Data Flow Diagrams - DFD).
  • تقييم المشكلات التشغيلية للمؤسسات وصياغة متطلبات الحلول البرمجية المؤتمتة.

🗺️ خارطة مفردات المقرر المعتمدة

الموضوعات المعتمدة في خطة المقرر (العلامة الخضراء توضح الموضوعات المغطاة):

✓ مفاهيم أساسية في النظم وعناصرها ✓ دور محلل النظم والمهارات المطلوبة ✓ دورة حياة تطوير النظام (SDLC بالتفصيل) ✓ مرحلة التخطيط ودراسة الجدوى وإدارة المشروع ⏳ تحليل الأنظمة وتحديد المتطلبات ⏳ تصميم المدخلات والمخرجات ونماذج البيانات ⏳ تصميم الإجراءات والمخططات (DFD / UML) ⏳ التنفيذ ودراسة الحالة التطبيقية

المحاضرة الأولى: أساسيات ونظم المعلومات

المحاضرة الثانية: محلل النظام وتطوير نظم المعلومات

ماهية عملية تحليل النظم والأسباب الأربعة الداعية لها، مؤهلات وصفات محلل النظم، الأدوار التخصصية الستة، المشاكل الأربعة وأساليب التحليل، والتفصيل الكامل لمراحل دورة حياة تطوير النظام (SDLC) الأربع ووثائقها.

المحاضرة الثالثة: مرحلة التخطيط ودراسة الجدوى وإدارة المشروع

خطوة إقلاع المشروع، صياغة وثيقة طلب النظام بعناصرها الخمسة، دراسات الجدوى الثلاث (تقنية، اقتصادية، تنظيمية)، هيكل تجزئة العمل (WBS)، مخططات جانت وبيرت، وخطة عمل المشروع.

04

المحاضرة الرابعة: مرحلة التحليل وتحديد المتطلبات

تفكيك النظام من الواقع الحالي (As-Is) إلى المستقبلي (To-Be)، تقنيات الاستنباط الخمس وقاعدة الـ 48 ساعة، استراتيجيات التحليل الثماني ومحاكي كفاءة العمليات PCE، ودراسات حالة Progressive و Southwest، وصياغة مقترح النظام الشامل.
