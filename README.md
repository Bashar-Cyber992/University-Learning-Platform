1. **الأمن السيبراني والشبكات (Cybersecurity & Networks)**
2. **تكنولوجيا المعلومات (Information Technology)**

تمت إعادة هيكلة المنصة بالكامل وفق أفضل ممارسات هندسة البرمجيات وتصميم الواجهات (Component-Based Architecture & Separation of Concerns)، مع توحيد كامل للتصميم البصري، وفصل الأنماط والسكربتات، وبناء نظام تصميم مركزي (Design System)، وتوحيد التذييل (Footer) والرأس (Header) كـ Single Source of Truth دون الاعتماد على خوادم خارجية أو كسر بروتوكول التشغيل المحلي (`file:///`).

## 🎨 نظام التصميم الموحد (Unified Design System)

### 1. رموز التصميم (Design Tokens)
تُدار جميع المتغيرات عبر ملف `assets/css/variables.css`:
- **نظام المسافات (Spacing Scale):** من `--space-1` (0.25rem) حتى `--space-16` (4rem).
- **مقياس الخطوط (Typography Scale):** خطوط عربية حديثة (`Cairo`, `Tajawal`) بمقاسات تبدأ من `--text-xs` (0.75rem) إلى `--text-4xl` (2.25rem).
- **ألوان الحالات (State Colors):**
  - النجاح (Success): `#10b981` / خلفية: `#ecfdf5`
  - التنبيه (Warning): `#f59e0b` / خلفية: `#fffbeb`
  - الخطأ (Danger): `#ef4444` / خلفية: `#fef2f2`
  - المعلومات (Info): `#0284c7` / خلفية: `#f0f9ff`
- **حواف دائرية وظلال موحدة:** `--radius-sm`، `--radius-md`، `--radius-lg`، `--card-shadow`، `--hover-shadow`.

### 2. هوية المقررات (Course-Scoped Themes)
لكل مقرر هويته اللونية الخاصة المنظمة من خلال وسم `data-course="[course-name]"` في عنصر `<body>`، ويتم تطبيق لوحة الألوان تلقائياً في الوضعين النهاري والليلي:
- `software-development-fundamentals`: الكحلي والأزرق الهادئ (`#1a365d` / `#2b6cb0` / `#ed8936`)
- `security-software-design`: النيلي والبنفسجي الأمني (`#1a365d` / `#553c9a` / `#ed8936`)
- `cloud-computing`: السماوي المتقدم (`#0369a1` / `#0284c7` / `#f59e0b`)
- `it-project-management`: الأخضر الإداري والذهبي (`#1e3a2b` / `#2f855a` / `#d69e2e`)
- `digital-forensics`: الرمادي الجنائي والعنابي (`#1e293b` / `#334155` / `#e11d48`)
- `systems-analysis-and-design`: الكحلي التحليلي (`#1a365d` / `#2b6cb0` / `#ed8936`)

### 3. نظام الأزرار الموحد (Button System)
تستخدم جميع الصفحات فئات موحدة للأزرار:
- `.btn.btn-primary`: الزر الرئيسي للمهام المحورية.
- `.btn.btn-secondary`: الزر الثانوي للعمليات البديلة.
- `.btn.btn-outline`: زر الحدود الشفاف للتنقل والاستعراض.
- `.btn.btn-danger`: زر الإجراءات الحرجة والتنبيهات.
- `.btn.btn-icon`: أزرار الأيقونات الدائرية والتفاعلية.
- تدعم جميع الأزرار حالات `:hover`, `:active`, `:focus-visible`, و `:disabled`.

## 🧩 التذييل والرأس كمرجع مركزي موحد (Single Source of Truth)

- **ملف `components/footer.js`:**
  - يمثل المصدر البرمجي الوحيد لتذييل المنصة.
  - لا توجد أي نصوص أو روابط تذييل مكررة داخل أي ملف HTML.
  - يحتوي على روابط المقررات الستة والمنصة الرئيسية، وبيانات الكلية، وعضو اللجنة العلمية م. بشار زبله.
  - يتعرف تلقائياً على المقرر المفتوح ويحقن اسم أستاذ المقرر المعني في التذييل.
  - يعالج الروابط النسبية ديناميكياً لتعمل بكفاءة مطلقة سواء تم فتح الملف عبر خادم ويب محلي أو مباشرة من القرص الصلب (`file:///`).
  - عند الحاجة لتعديل أي بيانات في التذييل، يتم التعديل في `components/footer.js` فقط لينعكس فوراً على جميع صفحات الموقع العشرين.

- **ملف `assets/js/main.js` و `components/header.js`:**
  - يدير التبديل بين الوضع النهاري والليلي ويزامنه عبر `localStorage` بالمفتاح `'theme'`.
  - يتولى حساب نسبة تقدم القراءة (`reading-progress`).
  - يدير تعقب الأقسام في القائمة الجانبية (Sidebar Scroll Spy).
  - ينفذ نسخ الأكواد مع إشعار فوري وتفاعل الأكورديونات وبطاقات الاستذكار (Flashcards).

- **محرك الكويزات الموحد `assets/js/quiz.js`:**
  - محرك موحد لجميع كويزات المحاضرات (`QuizEngine`).
  - يحتفظ بأفضل درجة حققها الطالب في `localStorage` مع تاريخ الإنجاز.
  - يقدم تغذية راجعة فورية لكل خيار مع الشرح التوضيحي.

## 💡 دليل إضافة محاضرة جديدة للمنصة

لإضافة محاضرة جديدة مع الحفاظ على الاتساق المعماري:
1. أنشئ ملف `Lecture-XX.html` داخل مجلد المقرر المناسب.
2. اربط ملف الأنماط المشترك في الرأس:
   ```html
   <link rel="stylesheet" href="../assets/css/main.css">
   ```
3. ضع السمة المناسبة في عنصر `<body>`:
   ```html
   <body data-course="[course-slug]">
   ```
4. أضف نقطة ربط التذييل الموحد في نهاية المحتوى:
   ```html
   <div id="site-footer"></div>
   ```
5. استدعِ الملفات البرمجية المشتركة ومحرك الكويز:
   ```html
   <script src="../assets/js/main.js"></script>
   <script src="../assets/js/components.js"></script>
   <script src="../assets/js/quiz.js"></script>
   <script>
       const quizData = [ /* مصفوفة أسئلة الكويز */ ];
       initLectureQuiz(quizData, 'quiz_[course]_[lec]');
   </script>
   ```
