منصة رقمية تفاعلية ومكتبة جامعية مفتوحة، مصممة خصيصاً لتحويل المحاضرات والمقررات الأكاديمية الخام إلى تجارب تعليمية ذكية، عميقة، ومستقلة (Standalone HTML). 

تم بناء هذا المستودع لتنظيم مسار التعلم في تخصص **الأمن السيبراني وهندسة الشبكات**، بحيث لا يقتصر على سرد المعلومات، بل يمتد إلى الشرح العميق، التطبيق العملي، والتقييم الذاتي.

---

## 🎯 الميزات الرئيسية للمنصة

- **🧠 شروحات منهجية وعميقة:** تفكيك المفاهيم الأكاديمية المعقدة إلى مراحل سلسة ومدعمة بالأمثلة العملية.
- **⚡ تقييم ذاتي تفاعلي (Quizzes):** اختبارات قصيرة نهاية كل قسم مع تغذية راجعة فورية لتثبيت المعلومة.
- **🗂️ أدوات استذكار (Flashcards):** بطاقات تعليمية تفاعلية لمراجعة المصطلحات التقنية والأكاديمية (مثل مصطلحات التحقيق الجنائي وتصميم النظم).
- **📱 تصميم متجاوب كلياً:** واجهات متوافقة تماماً مع شاشات الهواتف المحمولة، الأجهزة اللوحية، وأجهزة الحاسوب.
- **🚀 استقلالية تامة:** كل محاضرة تعمل كملف منفصل بذاته دون الحاجة لمكتبات خارجية معقدة.

---

## 📚 المقررات الدراسية (الفصل الحالي)

تضم المنصة حالياً مسارات التعلم للمقررات التالية:

1. **📊 تحليل وتصميم نظم (Systems Analysis & Design - SAD)**
   - دراسة دورة حياة تطوير الأنظمة (SDLC)، هندسة المتطلبات، ونمذجة البيانات.
2. **💻 أساسيات تطوير البرمجيات (Fundamentals of Software Development)**
   - منهجيات التطوير، دورة حياة البرمجيات، ومبادئ هندسة الكود النظيف.
3. **🛡️ تصميم البرمجيات الآمنة (Security Software Design)**
   - مبادئ الأمن بالاستناد إلى التصميم (Security by Design) ونمذجة التهديدات (Threat Modeling).
4. **☁️ الحوسبة السحابية (Cloud Computing)**
   - نماذج الخدمات السحابية، المحاكاة الافتراضية، وهندسة البنية التحتية السحابية.
5. **🔎 التحقيق الجنائي الرقمي (Digital Forensics)**
   - منهجيات جمع وحفظ الأدلة الرقمية، وتحليل البيانات والأنظمة والشبكات.
