# عينة تجريبية لاختبار منظومة الوكلاء: مفهوم الحوسبة السحابية (Cloud Computing Foundations)

## محتويات الشريحة 1:
- العنوان: ما هي الحوسبة السحابية؟
- التعريف: نموذج لتوفير وصول شبكي ملائم وعند الطلب إلى مجمع مشترك من موارد الحوسبة القابلة للتهيئة (مثل الشبكات، الخوادم، وسائط التخزين، التطبيقات، والخدمات).
- الخصائص الخمس الأساسية حسب NIST SP 800-145:
  1. الخدمة الذاتية عند الطلب (On-demand self-service).
  2. الوصول العريض للشبكة (Broad network access).
  3. تجميع الموارد (Resource pooling).
  4. المرونة السريعة (Rapid elasticity).
  5. الخدمة المقاسة (Measured service).
