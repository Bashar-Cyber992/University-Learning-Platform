🎯 أهداف المقرر الأكاديمية (13 هدفاً)

  1. الانتقال من البرمجة إلى التطوير الاحترافي: فهم الفرق بين كتابة الشيفرة وبناء منتج برمجي متكامل.
  2. إتقان أدوات التطوير: التعامل مع محررات الشيفرة، والطرفية، والمصححات، ومديري المكتبات والتبعيات.
  3. تحسين جودة الشيفرة: تطبيق مبادئ التسمية الواضحة، وتقليل التكرار، وإعادة الهيكلة (Refactoring).
  4. التصميم البرمجي الجيد: استخدام التجريد والتقسيم إلى وحدات ومبادئ SOLID الأساسية.
  5. مهارات التشخيص: اكتشاف الأخطاء البرمجية وتحديد أسبابها الجذرية وإصلاحها.
  6. الاختبارات الآلية: كتابة اختبارات تتحقق من صحة وظائف البرنامج وتمنع عودة الأخطاء.
  7. إدارة الإصدارات والتعاون: استخدام Git والفروع وعمليات الدمج ومراجعة الشيفرة.
  8. التعامل مع قواعد البيانات: تنفيذ عمليات CRUD مع المحافظة على سلامة البيانات والمعاملات.
  9. تطوير واجهات API: بناء خدمات تسمح للتطبيقات بالتواصل وتبادل البيانات عبر HTTP وJSON.
  10. أساسيات الأمن البرمجي: التحقق من المدخلات، وحماية كلمات المرور، ومنع ثغرات SQLi و XSS.
  11. تحسين الأداء: كتابة شيفرة تستهلك الموارد بكفاءة وتستجيب بسرعة.
  12. النشر والتشغيل: نقل التطبيق من بيئة التطوير إلى خادم حقيقي ومراقبة أدائه.
  13. بناء عقلية المهندس: التفكير التحليلي، والتعلم المستمر، وحل المشكلات المعقدة.

⚖️ مقارنة هندسية: الشيفرة النظيفة (Clean Code) مقابل الشيفرة القديمة (Legacy Code)

المعيار الشيفرة النظيفة (Clean Code) الشيفرة القديمة / غير المنظمة (Legacy Code)
قابلية القراءة واضحة ومباشرة؛ تقرأ كالنثر وتُفهم نيتها سريعاً. غامضة ومربكة؛ تحتاج جهداً كبيراً لتتبع مسار تنفيذها.
التسمية أسماء دلالية تصف الهدف والوظيفة بدقة. أسماء مختصرة أو مضللة مثل (x, temp, data1, func).
حجم الدوال دوال صغيرة ومحددة تؤدي مهمة واحدة فقط (Single Responsibility). دوال ضخمة تتجاوز مئات الأسطر وتؤدي مهام متعددة ومتشابكة.
التكرار (DRY) المنطق موحد ومُعاد استخدامه في دوال أو وحدات مستقلة. شيفرات مكررة ومنسوخة في مواضع متعددة من النظام.
الاختبارات مغطاة باختبارات آلية تضمن صحة التعديلات وسرعة اكتشاف الأخطاء. تفتقر إلى الاختبارات؛ أي تعديل قد يسبب انهيار أجزاء أخرى.
سهولة الصيانة التعديل والإضافة عليها سريع ومنخفض التكلفة والمخاطر. التعديل بطيء ومكلف ومحفوف بالخوف من حدوث أخطاء غير متوقعة.

🏆 مخرجات التعلم المتوقعة — بنهاية المقرر، يُتوقع أن يكون الطالب قادراً على:

1 تجهيز مشروع برمجي قائم وتشغيله وفهم مكوناته وبنيته التحتية.
2 قراءة الشيفرة المكتوبة مسبقاً وتحسين تنظيمها وإعادة هيكلتها (Refactoring).
3 تصميم وحدات برمجية واضحة وتقليل الترابط غير الضروري بينها.
4 استخدام أدوات تصحيح الأخطاء وكتابة اختبارات آلية فعالة تمنع الانحدار.
5 إدارة التغييرات باستخدام Git والتعاون الاحترافي في تطوير مشروع برمجي.
6 إنشاء تطبيق متصل بقاعدة بيانات علائقية مع تنفيذ عمليات CRUD الآمنة.
7 تصميم واجهة API واختبار طلبات واستجابات HTTP بصورة منهجية عبر JSON.
8 تطبيق ضوابط أمنية أساسية في الشيفرة ومنع الثغرات الشائعة (SQLi & XSS).

📝 واجب مشروع التطبيق العملي للترم

يُطلب من كل طالب (أو فريق ثنائي) بناء تطبيق برمجي مصغر يُغطي المحاور المدروسة، متضمناً:

  • مستودع Git مُدار باحترافية يحتوي على فروع ورسائل حفظ واضحة (Conventional Commits).
  • شيفرة برمجية تطبق معايير الشيفرة النظيفة (Clean Code) والتقسيم إلى وحدات مستقلة.
  • اتصال بقاعدة بيانات وإجراء عمليات CRUD مع معالجة الأخطاء والتحقق من المدخلات.
  • واجهة API بسيطة أو واجهة مستخدم تفاعلية تتواصل مع الخادم عبر صيغة JSON.
  • مجموعة اختبارات آلية تتحقق من صحة الوظائف الحيوية في التطبيق.
  • ملف توثيق (README.md) يوضح خطوات التثبيت والتشغيل وهيكل المشروع البرمجي.
