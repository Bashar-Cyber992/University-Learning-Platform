🎯 أهداف المقرر ومخرجات التعلم

  • فهم المعمارية الأمنية للبرمجيات وتطبيق مبادئ الحماية والتصميم الدفاعي متعدد الطبقات.
  • إتقان إدماج الأمن في دورة حياة تطوير البرمجيات (Secure SDLC) وتطبيق ممارسات DevSecOps.
  • تحديد حدود الثقة (Trust Boundaries) وتطبيق مبادئ أقل صلاحية (PoLP) والتحقق التام (Complete Mediation).
  • كشف وتحليل الثغرات البرمجية الشائعة (مثل SQLi و XSS) وتطبيق آليات البرمجة الدفاعية الوقائية.
  • تقييم خطورة التهديدات والثغرات الأمنية باستخدام معايير التقييم العالمية (CVSS).

🗺️ خارطة موضوعات المقرر المعتمدة

الموضوعات المعتمدة في خطة المقرر (العلامة الخضراء توضح الموضوعات المغطاة):

✓ مفهوم أمن البرمجيات و Safety ✓ مثلث الأمن المتوازن (CIA Triad) ✓ مبادئ وإرشادات المعمارية الأمنية ✓ حدود الثقة وعزل المكونات و Zero Trust ✓ دمج الأمن في SDLC و DevSecOps ✓ دورة حياة الثغرات وتصنيف الهجمات ✓ الاختبارات الأمنية (SAST, DAST, PenTest) ✓ بيئات التنفيذ المعزولة ومحاكاة Java Sandbox

01

المحاضرة الأولى: أمن البرمجيات وخصائص البرمجيات الآمنة (Software Security)

مفهوم أمن البرمجيات، مثلث CIA والتعريفات الدقيقة، الفرق بين الأمن والسلامة (Security vs Safety)، الخصائص الست للبرمجيات الآمنة، الأبعاد الأربعة للأثر التجاري، ونموذج المسؤولية المشتركة.

02

المحاضرة الثانية: مبادئ وإرشادات المعمارية الأمنية (Security Architecture)

مفهوم المعمارية الأمنية وأهدافها، تقسيم النظام وحدود المسؤوليات، حدود الثقة (Trust Boundaries)، مبدأ أقل صلاحية (PoLP)، الدفاع متعدد الطبقات (8 طبقات)، Deny by Default، Zero Trust، ومقارنة معماريتين لنظام جامعي.

🏛️ 3 مخططات معمارية SVG 🛡️ مستكشف الطبقات الثمان 🧪 مشخص العيوب المعمارية 🗂️ 8 بطاقات ✅ كوز من 10 درجات

03

المحاضرة الثالثة: الأمن خلال دورة التطوير ودورة حياة الثغرات (Security in SDLC)

إدماج الأمن بالتفصيل في المراحل الست لـ SDLC، الاختبارات الأمنية (SAST, DAST, SCA, PenTest)، تقييم الثغرات (CVSS)، مقارنة الهجمات على مستوى التصميم والتنفيذ (SQLi, XSS) والتشغيل، ودورة حياة الثغرة.

المحاضرة الرابعة: المعمارية الأمنية وبيئة التنفيذ المعزولة (Java Sandbox)

دراسة مفهوم Sandbox ومبدأ أقل صلاحية (Least Privilege)، معمارية JVM ومراحل عملها (Class Loader, Bytecode Verifier, Security Manager)، إيقاف Security Manager في Java 24 والبدائل الحديثة (Containers & JVM Options)، وبناء محلل ملفات الطلاب الآمن (Student Analyzer).
