🎯 أهداف المقرر ومخرجات التعلم

  • فهم المعمارية الأمنية للبرمجيات وتطبيق مبادئ الحماية والتصميم الدفاعي متعدد الطبقات.
  • إتقان إدماج الأمن في دورة حياة تطوير البرمجيات (Secure SDLC) وتطبيق ممارسات DevSecOps.
  • تحديد حدود الثقة (Trust Boundaries) وتطبيق مبادئ أقل صلاحية (PoLP) والتحقق التام (Complete Mediation).
  • كشف وتحليل الثغرات البرمجية الشائعة (مثل SQLi و XSS) وتطبيق آليات البرمجة الدفاعية الوقائية.
  • تقييم خطورة التهديدات والثغرات الأمنية باستخدام معايير التقييم العالمية (CVSS).
