🎯 المخرجات التعليمية للمقرر

  1. إتقان مفاهيم أمن البرمجيات والتمييز بين الصحة الوظيفية، السلامة التشغيلية، والأمن السيبراني.
  2. تطبيق خصائص السرية والسلامة والتوافر (CIA) ومبادئ التصميم الآمن الخمسة.
  3. دمج الأنشطة والضوابط الأمنية في كافة مراحل دورة حياة تطوير البرمجيات (SDLC).
  4. تحليل الأنظمة الحقيقية لتحديد الأصول والتهديدات والثغرات وحساب المخاطر وتصميم مصفوفة الصلاحيات.

المحاضرة الأولى: أمن البرمجيات وخصائص البرمجيات الآمنة (Software Security)

مفهوم أمن البرمجيات، المصطلحات الأساسية الثمانية، الفرق بين المصادقة والتفويض، مقارنة Software Security و Software Safety، مثلث CIA بالتفصيل، صحة البرنامج مقابل أمنه، دورة حياة التطوير الآمن (Secure SDLC) ومبادئ التصميم الآمن الخمسة، نماذج التطوير (Waterfall, Agile, DevSecOps)، والتطبيق العملي الشامل على نظام كلية المنار.

المحاضرة الثالثة: الأمن خلال دورة التطوير ودورة حياة الثغرات (Security in the SDLC & Vulnerability Life Cycle)
